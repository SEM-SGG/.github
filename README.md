# Startseite der Organisation SEM-SGG

Dieses Repository enthält den Text, den GitHub auf [github.com/SEM-SGG](https://github.com/SEM-SGG) über der Liste der Repositories anzeigt.

- **Öffentliche Fassung:** [`profile/README.md`](profile/README.md) in diesem Repository.

## Text ändern

1. Öffne `profile/README.md` und klicke auf den Stift (**Edit this file**).
2. Ändere den Text und klicke auf **Commit changes**.
3. Öffne [github.com/SEM-SGG](https://github.com/SEM-SGG) und prüfe das Ergebnis.

Kommt ein Werkzeug dazu oder fällt eines weg, ergänze oder entferne die Zeile in der Tabelle in beiden Fassungen. Kommt ein Werkzeug oder ein Issue-Formular dazu, führe auch die Tabelle «Rückmeldung geben» in beiden Fassungen nach. Der QR-Code mit der Adresse der Startseite (`https://github.com/SEM-SGG`) liegt in [`profile/rueckmeldung-qr.png`](profile/rueckmeldung-qr.png) und [`profile/rueckmeldung-qr.svg`](profile/rueckmeldung-qr.svg); beide Fassungen verlinken die PNG-Datei. Der Abschnitt «Datenregel» lautet in allen Repositories der Organisation gleich; ändere ihn nur überall gemeinsam.
